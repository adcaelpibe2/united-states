# United States

A simple and responsive state search app where you can type the name of any U.S. state and press Enter to instantly get the result. This project demonstrates real-time search functionality and clean frontend development using modern technologies.

## ✨ Features

- 🔍 Real-time search for U.S. states
- 🖱️ Press Enter to search
- 📱 Fully responsive design
- ⚡ Instant search results
- 🌙 Clean and user-friendly UI

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Responsive Web Design
